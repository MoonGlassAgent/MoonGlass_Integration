故事开始 · The Strip

1
SoC 接线像一团毛线——「把 UART 挂上」「地址随便编」……AI 一兴奋就随便连。 Chaos mode: AI wires whatever feels right. Spoiler: it isn't.

没有合约的集成 = 深夜 debug 派对（没人想来）。

2
先立合约：IP / Subsystem / SoC 三层 YAML + JSON Schema。端口、总线角色、地址图——写清楚再动手。 Contracts first. Schemas keep the story honest.

schemas/ · examples/ —— 描述驱动，不是又一个 IP-XACT 克隆。

3
Agent 读 AGENTS.md / 规则，再玩连连看：自然语言意图 → nl_field_map → 该改的 YAML 字段。 Agent-as-Elaborator: match NL, fill fields, elaborate top RTL.

人话进，合约出。先匹配场景，再动文件。

4
validate.py 是友善门卫：schema、bundle 闭包、bus_role 配对、fabric decode……不生成 glue HDL，只挡离谱。 Friendly gatekeeper. Thin validator — zero heavyweight engine.

python tools/validate.py —— 绿灯再 elaborator。

5
客串明星：fabric（decode/mux）、adapters、bit-slice——校验器认得它们；PicoSoC pilot 已实装走通一圈。 Sidekicks in the schema. Pilot-tested, still not an integrator product.

规则包验证 ✔ · 不是把 MoonGlass 变成接线厂。

6
为什么能替代传统集成工具？因为 IP-XACT / Block Design / coreAssembler 一类，本质上仍是信号关系的文本（或结构化）描述——GUI 多半是同一份关系的另一张皮。 本包用自研 YAML 契约把同样的关系说清楚，再交给 Agent 当场 elaborator；不必养一个永久 GUI / 集成器产品。 Traditional tools ≈ signal-relationship text. YAML contracts + Agent-as-Elaborator — no forever integrator factory. (Not a patent/legal claim.)

同类问题，更薄的真源；边界仍是「非永久集成器」，不声称法律/专利豁免。

7
边界打卡：我们不是永久集成器。AI 可以现场写一次性 glue；本包只提供合约、规则、薄校验。 Not a permanent integrator. Invent helpers; we don't ship the factory.

是规则包 + Agent elaborator · 不做永久集成器产品 · 不是 MoonGlass 内置接线功能。
